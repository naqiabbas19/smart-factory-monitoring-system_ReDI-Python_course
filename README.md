# Smart Factory Monitoring System

## 📌 Description
A Python-based Smart Factory Monitoring System that tracks machine production, calculates defect rates, monitors performance, and generates alerts for high defects. The system uses Object-Oriented Programming and supports data export in CSV and JSON formats with automated testing using pytest.

---

## ⚙️ Features
- Machine production tracking  
- Defect rate calculation  
- Machine performance ranking  
- Alert system for high defect rate (>20%)  
- CSV data export  
- JSON data export 
- Automated testing using pytest  

---

## 🛠️ Technologies Used
- Python  
- Object-Oriented Programming (OOP)
- Data processing and sorting algorithms
- CLI(command line interface)  
- CSV handling  
- JSON handling  
- Pytest (unit testing)
- GitHub
